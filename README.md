# NetworksV6 (DrakesCraft Edition)

An optimized fork of the Networks Slimefun addon, adapted for **DrakesCraft Network**.

## Features

- ⚡ High-performance item and energy transport networks.
- 📦 Reduced tick lag and optimized buffer management.
- 💾 1:1 compatibility with Slimefun4 data format.

## Compatibility

- Minecraft 1.21.11 / Slimefun4 Core
